# Challenge dataset

The organizer-provided TSV files from `6ab10eb3b23ba_student_resource.zip` are stored here using the layout from the problem statement:

```text
dataset/
  train/
    train_source1.tsv
    train_source2.tsv
    train_source3.tsv
    train_ground_truth.tsv
  test/
    test_source1.tsv
    test_source2.tsv
    test_source3.tsv
```

All files are tab-separated. The seven TSV files are kept local and excluded from Git. Download the organizer's archive separately to reproduce the pipeline.
